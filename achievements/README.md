# Achievements

This folder holds the running log of what you have done during the year.

Use one file per year for now unless your role changes or you need a separate log for a new review cycle.

Current rule:

- keep logging factual, specific achievements as they happen
- add direct evidence when available
- only infer an achievement from a conversation if it is obvious; otherwise ask first
- map each item to a goal, core value, or review theme when the link is clear

Use the [Capture agent](../.github/agents/capture.agent.md) for quick capture and the [Review Writer agent](../.github/agents/review-writer.agent.md) when you want entries mapped back to goals, objective lenses, or values.
