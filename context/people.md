# People Lookup

Everyone in this repo is referred to by **alias (initials)** only. This table maps each alias to a role so agents and readers can cross-reference consistently. Real names are deliberately not recorded here or anywhere else in the repo.

## Rules

- Write the alias in every file (e.g. "GL", "DA"). Add the role in brackets on first mention in a file when it helps the reader.
- Executives are referred to by role only (CTO, COO, CEO), not initials.
- When someone new appears, add them here **before** using their alias elsewhere. Check for clashes first — every alias must be unique.
- When someone leaves or changes role, update **Status** and **Role** here rather than rewriting historical entries.
- Team members' development context lives in [team](../team); this file holds only alias, role, and area.
