# Goal Example - Appium

Post MAUI, transition automation over to Appium starting with the MX Account site migration.

This objective has been completed:

- Learning - I learned Appium through paired delivery of the MVP with RW, who provided technical guidance and framework design support.
- Delivery - we designed and implemented the Appium MVP framework to cover the basic authentication flows and some basic scaffolding for the Bookings and Account journeys.
- Documentation - I helped peer review framework documentation produced by RW.
- Metrics - During the MVP I created a simple Excel model to monitor completion against the legacy pack.

I've set myself to "star" for this objective as producing this MVP, parallel to sprint work, was crucial to get buy in to progress Appium as a project and demonstrate the value gained by doing so.
