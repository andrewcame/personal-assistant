# Competency: AI Accelerated

## Scale

5 levels: Learn, Execute, Mentor, Manage, Strategise

### Score 1 - Learn
- Description: Adopts an agentic-first mindset from day one, whether shipping code or shipping test coverage. Directs agents to explore problems, generate options, generate tests or test cases, support debugging, and accelerate well-defined work. Validates outputs carefully, improves prompt quality over time, and starts to think in terms of desired outcomes, a shipped feature, a trustworthy test suite, rather than manual code or manual test-case production.
- Expectation: Think in outcomes, not code. Direct agents from day one and build the habit of shipping through orchestration.
- Expected example: A software engineer uses agents across investigation, implementation, and testing rather than only for code generation. A QA engineer uses AI to generate test ideas and explore edge cases, then validates every output before trusting it rather than accepting it at face value. Both improve their prompts and context after a weak result instead of giving up, and share a working pattern that helps teammates get better results in similar situations.
- Stretch example: Orchestrates a well-defined feature or test suite through several deliberate AI-assisted steps from intent to verified completion. Creates a reusable prompt, checklist, or small workflow, for code or for test generation, that improves repeatability for others. Shows clear judgment about when agentic help is useful and when deeper human validation is required, on both the code and the test side.

### Score 2 - Execute
- Description: Uses AI consistently as a delivery mechanism across well-defined work, whether that is shipping features or shipping test coverage. Designs clearer prompts and simple workflows, treats orchestration as normal engineering or QA practice, and improves pace without abandoning validation or judgment. Measures productivity in outcomes and value shipped, not effort expended.
- Expectation: Agentic-first, every task. Productivity measured in value delivered, not effort expended.
- Expected example: A software engineer orchestrates a well-defined feature through several AI-assisted steps: shaping, implementation, testing, verification support. A QA engineer uses AI to accelerate test generation and exploratory testing, then reviews outputs carefully before relying on them, keeping pace without letting quality slip. Both build and reuse prompt sequences or lightweight workflows for repeated tasks.
- Stretch example: Designs a more robust agent workflow for moderately complex work, feature delivery or test coverage, that other colleagues begin copying. Raises team pace on a feature or platform area by sharing a repeatable agentic approach that clearly works. Shows early judgment about which parts of a task should be delegated to agents and which require stronger human control.

### Score 3 - Mentor
- Description: Thinks and plans before directing. Decomposes more complex work, a feature or a test strategy, into orchestratable steps, designs repeatable workflows, evaluates what works, and helps others move from ad hoc prompting toward disciplined, outcome-focused agentic delivery.
- Expectation: Architect the approach, orchestrate the delivery, and accelerate the whole team.
- Expected example: A software engineer designs and evaluates multi-stage workflows for complex features, then iterates them based on what actually improves outcomes. A QA engineer directs agents across test generation, exploratory testing, and regression analysis, building repeatable workflows for their test area and sharing what works with colleagues. Both coach peers on prompting, context, and validation as a serious delivery mechanism.
- Stretch example: Accelerates squad-wide adoption enough that overall pace and leverage visibly improve, on both the code and quality side. Creates a reusable library of workflows or patterns, for engineering or test automation, that becomes part of how the squad operates. Solves a complex delivery or quality problem through disciplined orchestration that others could not yet do reliably.

### Score 4 - Manage
- Description: Sets the agentic-first standard for a squad or platform. Removes adoption blockers, defines what done fast and right looks like when agents are doing meaningful engineering or testing work, establishes guardrails, and ensures AI use increases real throughput and confidence, not just activity.
- Expectation: Lead humans and agents alike toward outcomes that manual delivery cannot match.
- Expected example: Defines the squad's practical standard for using AI well, prompting, validation, outcome accountability, and removes blockers slowing adoption. Leads AI-accelerated test engineering within a platform, setting the pace of agentic adoption across test generation, exploratory execution, and regression analysis, and coaching the team to work the same way. Coaches engineers or QA practitioners to use agents in ways that improve throughput without weakening quality.
- Stretch example: Transforms the squad or platform into a noticeably more outcome-driven, agentic team with clearer standards and higher leverage. Creates an AI operating pattern or playbook that other squads or platforms start adopting. Establishes measures that show whether agentic working is actually improving business-relevant delivery or quality outcomes, not just activity.

### Score 5 - Strategise
- Description: Sets the highest individual-contributor standard for agentic engineering or test engineering. Defines practical workflows, guardrails, and habits that make AI use effective in real delivery, then feeds successful patterns back into broader practice through chapters and close partnership with the Principal Software Engineer or QA and Test Engineering Manager.
- Expectation: Define what AI-native engineering looks like at scale and build the culture, platforms, and people that get you there.
- Expected example: Defines or sharpens the squad's direction for agentic engineering in a way engineers can use immediately. Measures delivery in outcomes and confidence shipped, not test cases written, and pushes agentic test engineering, coverage assessment, regression analysis, exploratory testing, ahead of where the rest of the function has reached. Uses evidence from their own delivery work to guide where the wider function should invest next in agentic capability.
- Stretch example: Partners on a practice, platform, or workflow that several squads later adopt. Turns the squad or platform into a clear example of disciplined agentic delivery that other teams learn from. Helps shape a wider AI operating pattern through grounded results, not theory.
