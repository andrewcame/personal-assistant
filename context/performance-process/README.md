Everything about how PureGym runs performance management, in one place: HR's source decks, the process summaries, objective lenses, and the review style examples. Used by the Goal Builder, Review Writer and Calibration Prep agents.

| [objective-lenses.md](objective-lenses.md) | People Developer / Value Creator / Business Operator | Goal Builder, Review Writer, Capture |
| [review-examples/](review-examples/README.md) | AC's own review writing as the style reference | Review Writer |

Read the summaries, not the PDFs; open a PDF only to check a detail. Process only lives here: no ratings, matrix positions, or details of PDP/PIP for individuals ([writing standard](../../team/README.md#writing-standard)).

Not here, on purpose: the role frameworks for the QA team ([qa-banding](../qa-banding/README.md), [team-roles](../team-roles/README.md)) are about level expectations rather than the HR process, so they stay in `context/`.
