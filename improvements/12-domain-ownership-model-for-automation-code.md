# Improvement 12 — Domain Ownership Model For Automation Code

- Each lead becomes responsible for the automation code in their area, with shared areas (e.g. IDS) co-owned so shared responsibility does not become no responsibility.
- Flaky test packs are identified and a response agreed: easy fixes go straight to the backlog; harder ones are assessed for value before committing resource; engineering support requested where needed.
