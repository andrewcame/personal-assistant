# Challenges

Numbered records of open management problems — things you're still working through, as distinct from [improvements](../improvements) (initiatives you've chosen to pursue) and [initiatives](../initiatives) (formal, sponsored proposals).

## Format

One file per challenge, numbered sequentially (`NN-title.md`). Each covers: context, the challenge, questions to explore, initial position, status & next action. Add dated evidence updates below rather than rewriting the original position; when a status or next action is overtaken, mark the old one superseded.

Status values: **Open**, **Active monitoring**, **Resolved**, **Closed — no longer relevant**.
